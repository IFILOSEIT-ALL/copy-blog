# 生生不息

### Start

本来年报还在写，公司让我负责项目升级vue3的方案，当时已经吐槽过一次了。  
北京出差回来后，被派了单独负责把项目升级到vue3的任务，不只是方案了。  
如何形容这个项目呢—复杂又特别混乱。

复杂在

```
   - 源代码文件: 300+ 个
   - Vue 组件: 150+ 个
   - JavaScript 文件: 约100个
   - 功能繁多，但是硬件的内部系统所以不例举
```

混乱在

> 组件的相关代码分散在多个位置、同一个功能的api分散在不同的子目录、根目录的各种位置。比如登录相关的api接口分别在4个文件中定义；
>
> 一个属性同时存储在Vuex中、sessionStorage中、Cookie中。从git上看是不同的人只写自己的代码，不管规范，但这个公司只有一个前端，所以项目经历了几手我也不好说；
>
> 目录结构混乱，不同目录下有同名组件，系统配置文件分散；
>
> 样式混乱，各种覆盖，比如为ElementUI写了独立的样式文件，但在app组件、layout组件中还在等覆盖写，且向下覆盖。
>
> 以及等等问题...

自认为自己是一个好人，在有回报的团队工作中，无作用无付出会让我觉得难受。  
所以很认真的和这个任务斗争了。  
但它开头真的太难，无从下手。它和那个游走在身后，总是给我一种被打量、被审视感的部长一起，压的我喘不过气。  
这一周尝试过兼容模式，尝试过新建项目，可混乱的结构让我根本没把项目跑起来。到周末又奔波了一下其它事，没忍住情绪崩溃了。

### Keep Going

不过不知道是心灵锚点还是条件反射，但奔溃几秒总会想起艾伦耶格尔，会让我止住。  
总之，当时调整好了心态，本着早就决定实习完离职的想法，和实习生的薪水，不会再担心部长怎么想怎么看我，不会被别人的期待绑架，不会把压力放在自己身上，做好在做的内容就行。  
很感谢这些把我推向改变的人，或力。

# Stable Diffusion

22年底玩过俩月，搞了些模型和使用方法，跑的还比较满意。  
结果后面个大厂都推出了自然语言ai生成，效果好得多，还能保持同人物不同服装动作，轻轻松把我花功夫学的东西踩进鞋底缝里。怒删之，等大厂开发的更好了再来用。
时隔几年想重新试试ai绘图，去看了看这几年听得多的Midjourney和nano banana，结果都是闭源云端的，还有审核。  
最终无敏感词的开源本地方案还得是Stable Diffusion。于是重新部署了，秋葉大佬的整合包太强了。

# 总结

感觉是行动力变强的一个月，虽然自由支配时间不多，但确实有很多运动和出门，也没有拖欠什么事，  
除了3月去日本玩的计划，央妈不建议去，本来我是不听的，因为蕾塞电话亭都加到行程内了。  
后来逛了一下日区推特，好像还是有一些人恨中国的...就算概率很低也还是先不去冒险吧。终极愿望仍然是希望，**世界和平，没有仇恨**。

月底是周六会回重庆一趟，所以这个月只有两次周末在家，两个周末依然做了很多事。  
最大的原因是摆脱B站了，不只是因为b站现在全是零碎无意义的短视频，而是对横屏长视频也厌了。  
比如影视飓风又在科普，lks又在整活，何同学弄了个很厉害的钢琴，阿狸不是受、大狸子这些博主在讲我已经不关注的硬件。
以及1w个up在拍的“我在百大采访/整活/突击其它百大”。  
当然关注的这些up的作品质量很优秀，影视飓风的知识很硬核，何同学的坚持的浪漫也很励志。但我不必全部接收，我会喜欢小鹿《用一只帆船环游世界》的新奇视角，也可以不必看《热度褪去的山西》和评测等内容。他们也都很棒，但太多重复的内容不值得霸占我的生活。
